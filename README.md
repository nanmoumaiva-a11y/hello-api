# hello-api
Ma premier API REST avec Spring Boot.

## Technologies
- Java 17
- -Spring Boot4.1.1
- -Maven

  ## Lancer le projet
  1. Cloner le depot
  2. Lancer : ./mvnw sprint-boot:run
  3. Ouvrir http://localhost:8080/hello

  ## Endpoint
  - GET /hello :renvoie{"message":"Bonjour Spring Boot!"}
